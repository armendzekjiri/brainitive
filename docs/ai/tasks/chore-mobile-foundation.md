## Problem / goal
Start the Expo mobile app. The old plan (14 phases, 121 rows) aimed at full web parity. Decision of the
owner (2026-11-03): **a companion app for everyday users**, not a copy of the web app.

## Scope (mobile v1)
| In the app (native) | Stays on web / desktop ("Open in Brainitive" → browser) |
|---|---|
| Connect / switch servers, sign in (system browser, PKCE), switch workspaces, profile | Billing, plans, invoices, clients, rates |
| Notifications inbox + push | Lead form builder, leads, helpdesk, feedback / client portals |
| Quick capture, inbox, share sheet | Admin, workspace / project settings, members, imports / exports |
| Today / My Day, task lists (Todoist-like: create lists and tasks) | Booking page creation and settings, calendar provider connections |
| Boards (view, move cards), issues (create / edit), comments | Column / custom field setup, scrum planning, sprint reports |
| Docs: read, **write and create pages**; bookmarks; snippets | Live co-editing, version history, whiteboards |
| Calendar (events), bookings (view / cancel), Gantt plans (view) | Automations, webhooks, GitHub, AI tools, time tracking / timesheets |

Not mentioned by the owner and so left web-only for now (easy to bring back): whiteboards (view), time
tracking, helpdesk for agents.

## Decisions
- **Hybrid, mostly native.** Native screens for the scope above; web-only flows open in the system
  browser (not an in-app webview) — keeps App Store guideline 4.2 (minimum functionality) safe.
- **Expo SDK 58** (React Native 0.88, Expo Router), Continuous Native Generation: `android/` and `ios/`
  are generated by `expo prebuild` and not committed.
- Identity: name **Brainitive**, bundle id / package **`app.brainitive.mobile`**, scheme
  **`brainitive://`** (the server's `mobile` client already redirects to `brainitive://auth/callback`).
- Licence: BSL 1.1 like the desktop app ("Brainitive Mobile 0.1.0 and later").
- **Testing:** Android emulator on this Windows/WSL machine; iOS later on the MacBook.
- App Store risks found: 4.8 (needs **Sign in with Apple** next to Google / GitHub / Microsoft →
  BRAI-449), 3.1.1 (no billing links on iOS), 5.1.1(v) (account deletion entry) → BRAI-450.
- Server work the app needs: **push delivery** (APNs / FCM; the API only stores `push_token` today) →
  BRAI-448.
