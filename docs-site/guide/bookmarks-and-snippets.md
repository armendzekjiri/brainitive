# Bookmarks and snippets

Bookmarks and snippets live at the workspace level, outside projects. Use them for the links, notes and bits of code
your team keeps coming back to.

## Bookmarks

Click **Bookmarks** in the sidebar. Bookmarks are grouped in **collections** ("Research", "Reading list", "Tools").

### Create a collection

Click **New bookmark collection**, give it a **Name**, an optional **Description** and an icon, and choose the
**Visibility**:

- **Private** – only you and the collaborators you invite can see it.
- **Shared** – anyone with the link can view it (read-only).

### Add to a collection

Open a collection and use **Add to bookmark**. You can add:

- a **Link** (paste a URL),
- a **File** (up to 200 MB),
- a **Note**,
- a **To-do** that you can tick off.

Quickest of all: press **Ctrl+V** (**⌘V** on Mac) on the collection page to paste a link, text or file straight from your
clipboard. You can also drop files onto it.

### Collaborators

Invite workspace members to a private collection as **Viewer** or **Editor**, change their role or remove them at any
time.

## Snippets

Click **Snippets** in the sidebar for reusable text and code: configs, commands, SQL queries, email templates.

1. Create a **New Snippet Collection** with a name, description and visibility (**Private** or **Public**).
2. Open it and click **New Snippet**. Enter a **Title**, pick the **Language** (Plain text, JavaScript, TypeScript,
   Python, PHP, Bash / Shell, SQL, HTML, CSS, JSON, YAML, Markdown and more), paste the **Content** and choose the
   visibility.
3. Click **Add Snippet**.

Snippets are shown with syntax highlighting. Copy one with a click, or copy the share link of a public snippet or
collection.

Only workspace editors and admins can add, change or delete snippets and collections.

## Save from anywhere

- Press **C** for [quick capture](./my-work#quick-capture) and organize the capture into a bookmark or snippet later.
- With the browser extension you can save the page you're on to a bookmark collection, or select code on any page and
  save it as a snippet — see [Apps, extension and shortcuts](./apps-and-shortcuts).
- The command palette (**⌘K**) has **Create Bookmark** and **Create Snippet**.
