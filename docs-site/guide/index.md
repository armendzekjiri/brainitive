# Using Brainitive

Brainitive brings boards, docs, whiteboards, plans and your customer-facing pages together in one workspace. This guide explains every part in plain language — start with workspaces and projects, then jump to whatever you need.

::: tip New here?
Read [Workspaces and projects](./workspaces-and-projects) first, then [Boards and issues](./boards-and-issues). Everything else builds on those two.
:::
