# Apps, extension and shortcuts

Brainitive runs in your browser, but it doesn't have to feel like a website. Install it as an app, add the browser
extension, and learn a few shortcuts.

## Install Brainitive as an app

Brainitive can be installed like an app on phones, tablets and computers. It then opens in its own window, with its own
icon, and can send push notifications.

- **iPhone / iPad** – open Brainitive in Safari, tap **Share → Add to Home Screen**. (Push notifications on iOS only work
  in this Home Screen app.)
- **Android** – in Chrome, open the menu and choose **Install app** or **Add to Home screen**.
- **Desktop (Chrome, Edge)** – click the install icon in the address bar, or use the browser menu → **Install**.

On phones, a round button lets you [capture an idea](./my-work#quick-capture) from anywhere.

## Browser extension

The Brainitive extension for **Chrome**, **Edge** and **Firefox** saves what you find on the web in two clicks:

- **Create an issue** from any page — with the link, the text you selected and a screenshot of the whole view or an
  area you drag.
- **Save a link** to a bookmark collection.
- **Clip** an article or a selection as a doc (draft or published).
- **Add a task** with a due date.
- **Inbox** tab: save the page to your [captures](./my-work#the-captures-inbox) to organize later.
- **Save code or text as a snippet**: select it and right-click → **Add selection to snippets**. The language is
  detected.
- Keep **My Work** open in the side panel.

It works with Brainitive Cloud and with self-hosted servers: you sign in on your own server. The extension can only save
things and search titles — it can't read your documents. You can disconnect it under
**Profile settings → Connected apps**.

### Get the extension

- **Chrome, Edge, Brave** – install [Brainitive from the Chrome Web Store](https://chromewebstore.google.com/detail/brainitive/mnnkcbjdgphgiiapdfegpgdmjekofmjn)
  with **Add to Chrome**, then pin it from the puzzle icon.
- **Firefox** – until it's on Firefox Add-ons, download it from the **Get the extension** section of the Brainitive
  homepage, open `about:debugging` → **This Firefox** → **Load Temporary Add-on** and pick the zip.

### Extension shortcuts

| Shortcut | Action |
|---|---|
| `Alt+Shift+B` | Open the extension |
| `Alt+Shift+S` | Screenshot an area |
| `bt` + space in the address bar | Search Brainitive |

## Keyboard shortcuts

### Everywhere

| Shortcut | Action |
|---|---|
| `⌘K` / `Ctrl+K` | Command palette: search and commands |
| `Ctrl+.` (or type `>` in the palette) | Commands only |
| `C` | Quick capture (when you're not typing) |

### Search page

| Shortcut | Action |
|---|---|
| `/` | Jump to the search field |
| `↑` `↓` `Enter` | Move through results and open one |

### Inbox

| Shortcut | Action |
|---|---|
| `j` / `k` | Next / previous notification |
| `Enter` | Open |
| `e` | Archive / unarchive |
| `u` | Mark read / unread |
| `x` | Select |

### Docs and issue descriptions

| Shortcut | Action |
|---|---|
| `/` on an empty line | Insert menu (headings, lists, tables, smart links …) |
| `⌘⇧V` / `Ctrl+Shift+V` | Paste a Brainitive link as a plain link instead of a smart link |

### Gantt plans

| Shortcut | Action |
|---|---|
| `Enter` | Next row |
| `Tab` / `Shift+Tab` | Indent / outdent a row |
| `Alt+↑` / `Alt+↓` | Move a row up / down |
| `⌘Z` / `Ctrl+Z`, `⌘⇧Z` / `Ctrl+Y` | Undo / redo |
| `⌘D` / `Ctrl+D` | Duplicate rows |
